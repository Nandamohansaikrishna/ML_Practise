📌 Context & MotivationIn my previous project, the Credit Risk Scorer & AI Advisor, I developed an end-to-end classification system. That project required handling complex tabular data through systematic EDA, feature engineering (outlier capping, SMOTE on 29 features), model training (Random Forest vs. Logistic Regression), and explainability (SHAP TreeExplainer).Building that system highlighted a critical engineering reality: knowing how to call a model is different from knowing which model architecture optimally handles specific dataset scales, feature dimensions, and latency constraints.This repository is a rigorous 7-day sprint designed to master those classical machine learning mechanics before transitioning to Deep Learning architectures.
🎯 Repository ObjectivesRather than treating machine learning as isolated scripts, this repository tackles real-world data constraints by implementing:Zero-Leakage Pipelines: Strict separation of fit/transform states to prevent artificial metric inflation.Algorithmic Selection: Benchmarking linear models against tree ensembles to understand performance trade-offs on varying dataset sizes.Production Packaging: Moving beyond Jupyter notebooks to serialized artifacts (ONNX/Joblib) and FastAPI serving.
🗓️ 7-Day Architecture Plan:
Day 1: Data Pipelines & Feature SelectionModular ColumnTransformer with automated variance thresholding.
Day 2: Regularized Regression & Diagnostics$L_1$/$L_2$ penalties and residual error analysis.Day 3: Classification Margins & CalibrationLinear vs. Non-linear boundaries with business-loss optimization.
Day 4: Tree Ensembles & Bayesian TuningGradient boosting (LightGBM/XGBoost) optimized via Optuna.
Advanced topics:
Day 5: Validation & Explainability (XAI)Out-of-fold generalization checks and SHAP waterfall plots.
Day 6: Clustering & Dimensionality ReductionPCA/UMAP latent space projection and density-based clustering.
Day 7: Anomaly Detection & SerializationCovariate shift tracking and ONNX model export with Pydantic.
🚀 Capstone Implementation for Following the 7-day sprint, these foundational modules will be integrated into a single Capstone Project. This project will demonstrate how to package the optimized classical models into a scalable inference pipeline, dealing with raw, messy data streams just like a live production environment.
⏭️ Future RoadmapUpon completing this repository and validating the classical ML capstone, the exact same rigorous validation, data hygiene, and modular pipeline standards will be applied to a new repository focused entirely on Deep Learning and custom neural network architectures.
